# Japan Festival Calendar

이 웹사이트는 [**japan-festival-calendar**](https://jfestcal.vercel.app/)에서 호스팅되고 있습니다.

일본의 다양한 축제와 이벤트 정보를 한눈에 볼 수 있는 달력 앱입니다.
